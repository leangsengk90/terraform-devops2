About This Application

This is a custom Nginx application running in a Docker Swarm cluster on AWS. It demonstrates a production-ready containerized web server with optimized configuration, security headers, and health monitoring capabilities.

Infrastructure Architecture

The application is deployed using Infrastructure as Code (IaC) with Terraform, creating a robust, scalable, and secure environment in AWS. The infrastructure includes VPC with public and private subnets, Application Load Balancer, Auto Scaling Groups, and comprehensive monitoring.

Features

Security: Security headers, HTTPS support, and network isolation.
Performance: Optimized Nginx configuration with gzip compression.
Scalability: Auto-scaling based on CPU utilization.
Monitoring: Health checks, metrics, and CloudWatch integration.
High Availability: Multi-AZ deployment with load balancing.
